About this trial

RELEASE is a randomised controlled trial comparing Airway Pressure Release Ventilation (APRV) with conventional ventilation in patients with moderate–severe acute hypoxaemic respiratory failure, defined by P:F ratio thresholds. The trial is in active recruitment at our site.
